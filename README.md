# FlowMic 🎤 — Whisper Flow adapté mobile

## 📲 Installer en 1 clic

**Sur ton Android, ouvre ce lien et installe :**

👉 **https://github.com/dominiqueadinkpo0-cmd/WhisperFlowMobile/releases/latest/download/FlowMic.apk**

1. Ouvre le lien → télécharge `FlowMic.apk`
2. Ouvre le fichier → Autoriser → Installer
3. Ouvre FlowMic → active Accessibilité + Survol + Micro → active le micro flottant

## Utilisation

* **Maintiens 🎤** → parle → **relâche** → le texte se tape tout seul dans le champ (WhatsApp, SMS, Chrome…)
* **Tap court** = dictée 8 secondes
* **Glisse 🎤** pour le déplacer
* Sans champ texte focus : texte copié, colle-le à la main
* **Historique** dans l'app : Copier / Taper à nouveau

## Moteurs

* **Google gratuit** : rapide, offline si pack vocal FR installé
* **Whisper API** : plus précis, multilingue — colle ta clé `sk-...` dans les réglages

## Permissions

Accessibilité (injection texte) + Survol d'écran (bouton flottant) + Micro. 100% local sauf si Whisper API choisi.
